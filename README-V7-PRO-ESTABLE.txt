SD COMAYAGUA · V7 PRO ESTABLE

Cambios principales:
1. Selector de productos de cotización corregido: ya no queda un espacio grande arriba de “Seleccionar producto”.
2. Foto para cliente más estable en Android/WhatsApp: menos riesgo de salir negra, gris o con letras invisibles.
3. Imagen del producto en inventario sin recorte agresivo; se mantiene completa dentro de la tarjeta.
4. Totales Producto / Envío / Al recibir reducidos y en una sola fila.
5. Acciones de cotización compactas para que no tapen contenido.
6. Panel móvil ajustado para evitar palabras jaladas, botones cortados o sensación de zoom.
7. Cache actualizado a v7-pro-estable para que GitHub Pages cargue los cambios nuevos.

Instalación en GitHub Pages:
- Sube/reemplaza todos los archivos del ZIP completo en el repositorio.
- Si solo quieres parchear, sube los archivos del ZIP de parche respetando las carpetas.
- En el teléfono, después de subir, abre la página y agrega ?v=7-pro-estable al final una vez, o borra caché del navegador si mira la versión vieja.
