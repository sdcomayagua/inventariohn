# SDC Gamer Ops V56

Versión para GitHub Pages del panel privado de ventas de SD Comayagua.

## Subida rápida

1. Sube todos los archivos a la raíz del repositorio.
2. En GitHub activa **Settings > Pages > Branch: main > /root > Save**.
3. Abre `app-v54-compacto-mobile.js` y cambia la variable de contraseña antes de usarlo.

Usuario administrador: `sdcomayagua`

> Seguridad básica: al ser frontend en GitHub Pages, la protección solo oculta el panel. Para seguridad real se necesita backend.
