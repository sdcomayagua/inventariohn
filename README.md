# SD Comayagua · Sistema de ventas limpio

Paquete ordenado para subir a GitHub Pages o a un hosting estático.

## Archivos principales

- `index.html`: entrada principal.
- `css/styles.css`: diseño base.
- `css/v1-polish.css`: ajustes visuales móviles.
- `css/sdc-stability.css`: correcciones de desplazamiento y foto para cliente.
- `js/config.js`: datos generales del negocio.
- `js/data.js`: productos iniciales.
- `js/storage.js`: guardado local y migración de datos previos.
- `js/app.js`: lógica principal.
- `js/sdc-stability.js`: protección para que el desplazamiento no se quede bloqueado.

## Nota

Sube todos los archivos y carpetas manteniendo la misma estructura.
