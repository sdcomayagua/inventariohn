# SD COMAYAGUA - V60 Gamer Ultra GitHub Pages

Archivo principal: `index.html`

## Cómo subirlo a GitHub Pages
1. Descomprime este ZIP.
2. Sube `index.html` a tu repositorio de GitHub Pages.
3. Abre la URL de GitHub Pages.

## Importante
Esta versión funciona como página estática para GitHub Pages.
El código de acceso del HTML solo oculta visualmente la página, pero no es seguridad real porque GitHub Pages es público.

Código visual de acceso por defecto dentro del archivo: SDC2026
Puedes cambiarlo en la línea:
const ACCESS_CODE = "SDC2026";

## Qué incluye
- Diseño gamer oscuro, diferente al estilo anterior.
- Catálogo móvil de 2 columnas.
- Buscador y filtros.
- Agregar/editar/eliminar productos en localStorage.
- Carrito de ventas.
- Recibo adaptado al nuevo estilo.
- Botón para imprimir/guardar PDF.
- Botón de WhatsApp.
