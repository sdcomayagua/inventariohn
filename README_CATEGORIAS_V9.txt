SD COMAYAGUA V9 - Categorías visuales

Cambios agregados:
- Nueva sección CATEGORÍAS con tarjetas e imágenes SVG.
- Se agregaron 70 archivos .svg en assets/categorias/ para categorías actuales y futuras.
- El buscador ya no reconstruye toda la página mientras escribes; solo actualiza el inventario.
- Esto evita el salto de pantalla/teclado en celular cuando escribes letra por letra.
- Las categorías se filtran tocando la tarjeta o los chips.

Carpeta nueva:
assets/categorias/

Si agregas una categoría nueva, la página intentará usar un archivo con el mismo nombre en formato slug.
Ejemplo:
Categoría: Gamer Móvil -> assets/categorias/gamer-movil.svg
Categoría: Audífonos Tipo C -> assets/categorias/audifonos-tipo-c.svg

Si no encuentra imagen exacta, carga la imagen genérica categoria.svg.
