SD COMAYAGUA - V8 IMPORTADOR CSV/XLSX

Para importar productos:
1. Entra al panel.
2. Toca Backup.
3. En Importar productos CSV/XLSX selecciona el modo:
   - Actualizar por código y agregar nuevos: conserva ventas y actualiza productos con el mismo código.
   - Reemplazar todo el catálogo: borra el catálogo actual y deja solo el archivo.
4. Toca Importar .CSV o .XLSX.

Columnas aceptadas:
codigo, nombre, categoria, precio, costo, stock, imagenes, promos, descripcion

Promos aceptadas:
1:25 | 2:50 | 3:69
o
1=25
2=50

Importante: para .xlsx la página usa una librería externa de Excel. Si no carga, usa CSV UTF-8.
