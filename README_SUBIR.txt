SD COMAYAGUA - V7 Fuente gamer fina + precios rápidos por cantidad

Subida a GitHub Pages:
1. Descomprime este ZIP.
2. Sube / reemplaza todos los archivos en tu repositorio de GitHub Pages.
3. Mantén index.html, css, js y assets en la misma estructura.
4. Abre la página en el celular y prueba Ver producto > cantidad > descargar / compartir.

Cambios V7:
- Nueva fuente gamer más fina: Chakra Petch + Barlow.
- Menos negrita y menos separación en letras.
- En Ver producto se agregó selector rápido de cantidad: 1, 2, 3, 5, 10, 12 y cantidad manual.
- La imagen para cliente ahora cambia según cantidad.
- La ficha muestra: Solo producto, Con Envío Normal y Pagar al Recibir +6%.
- Si el cliente ya tiene otros productos, se usa Solo producto para no duplicar envío.
