SDC V14 - Retoques PRO Móvil

Cambios aplicados:

1. Se agregó botón pequeño "Pro/Gamer" en la barra superior.
   - Pro cambia el aspecto a una versión más limpia/profesional.
   - Gamer devuelve el diseño original gamer.
   - La preferencia queda guardada en el dispositivo.

2. Se mejoró la imagen pública del producto.
   - Ahora muestra marca, foto, precio, descripción más ordenada, cantidad consultada y tres totales claros:
     Solo producto, Depósito/Tigo + envío, y Pagar al Recibir.
   - Se agregó explicación breve del proceso de pago para Envío Normal y Pagar al Recibir.
   - La imagen se exporta con más resolución.

3. Se mejoró el texto que se manda por WhatsApp.
   - Explica mejor Envío Normal: producto + Lps. 110, por depósito, transferencia o Tigo Money.
   - Explica mejor Pagar al Recibir: producto + Lps. 100 + comisión del 6%.

4. Se rediseñó la factura/cotización para que sea más compacta.
   - Pensada para una sola página tamaño carta al imprimir o guardar en PDF.
   - Tabla más pequeña, resumen claro y proceso de pago visible.
   - El botón PDF ahora imprime solo el documento, sin paneles ni botones.

5. Se mejoró la edición de recibos guardados.
   - En Caja / Recibos ahora el botón dice Editar.
   - Al guardar cambios no duplica la factura.
   - Ajusta el stock por diferencia cuando aumentas o reduces cantidades.

6. Se mantuvo la estructura base que ya te gustaba.
   - No se cambió el flujo principal.
   - No se eliminaron botones importantes.
   - Se priorizó uso desde celular.
