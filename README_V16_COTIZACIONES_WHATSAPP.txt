SDC V16 - Cotizaciones guardadas y WhatsApp móvil

Cambios aplicados:
1. Se agregó botón "Cotizaciones" en el panel principal.
2. Se agregó lista de cotizaciones guardadas con búsqueda por cliente, teléfono, código o producto.
3. Desde una cotización guardada se puede: abrir/modificar, pasar a venta, enviar por WhatsApp o borrar.
4. El botón "Guardar cotización" ahora actualiza la cotización abierta y evita duplicados.
5. Las imágenes descargadas de cotización/recibo llevan nombre único con cliente/teléfono, fecha y código.
6. Las imágenes de producto descargadas también llevan nombre único para no reemplazar la anterior.
7. En celular, el enlace de WhatsApp intenta abrir la app con whatsapp://send en lugar de mandar directo a WhatsApp Web.
8. Se mantiene la parte visual gamer/pro-gamer y las fuentes originales Barlow + Chakra Petch.

Nota:
Por seguridad de WhatsApp, una página web normal no puede adjuntar automáticamente una imagen a un número específico sin usar la API oficial de WhatsApp Business. Por eso la página descarga la imagen con nombre correcto y abre WhatsApp con el texto al cliente.
