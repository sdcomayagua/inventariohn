# SDCOMAYAGUA · V33 Full Maravilla

Versión mejorada para GitHub Pages con enfoque **móvil primero**.

## Cambios principales

- Apariencia más limpia, empresarial y moderna.
- Vista celular más compacta: menos espacio vacío y mejor lectura.
- Encabezado fijo más profesional.
- Hero/banner reducido para que el catálogo aparezca más rápido.
- Buscador corregido para que no se corte en celular.
- Dock inferior mejorado tipo app.
- Tarjetas de productos más limpias y ordenadas.
- Modales de producto y venta tipo app/bottom sheet en celular.
- Corrección reforzada para los botones:
  - Agregar producto
  - Nueva venta
  - Vender
  - Producto
- Service Worker actualizado para evitar que cargue la versión anterior.

## Archivos nuevos

- `style-v33-maravilla.css`
- `fix-v33-maravilla.js`

## Recomendación al subir a GitHub

Subir y reemplazar todos los archivos del repositorio.

Después de publicar, abrir la página en el celular y borrar caché o hacer recarga fuerte si sigue apareciendo la versión anterior.
