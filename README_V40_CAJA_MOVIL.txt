SDCOMAYAGUA · V40 Caja Móvil

Versión enfocada en uso privado desde celular.

Cambios aplicados:
- Productos primero: se ocultó el hero grande para que al entrar se vea buscador, categorías y catálogo.
- Header más pequeño y estable en móvil.
- Buscador corregido: ya no encima letras ni ocupa demasiado espacio.
- Categorías tipo chips compactas y desplazables horizontalmente.
- Tarjetas de producto más pequeñas, dos por fila en celular, con precio, stock y botones rápidos.
- Menú inferior nuevo: Productos, Venta, Factura y Ajustes.
- Venta/factura funciona como carrito editable: se pueden agregar varios productos, cambiar cantidad, editar precio, descuento, envío y luego generar factura.
- Botón de modo captura: limpia la pantalla para enviar captura al cliente.
- Vista de producto más vendedora: foto grande, precio, stock, botón para agregar a venta, descargar foto y copiar texto.
- Modo claro/oscuro mejorado con estilos propios de V40.
- Login más compacto para que SDCOMAYAGUA no se corte.
- Cache actualizado a V40 para evitar que GitHub Pages muestre archivos viejos.

Nota:
Esta versión no cambia tu API_URL ni tu Apps Script. Solo agrega una capa visual y de interacción encima de la V39.
