# SDC V28 — Limpieza + Pro Gamer Premium

## Qué se limpió
- Se eliminaron los archivos `LEEME` y `README` antiguos del directorio principal.
- La guía de nube quedó en `docs/GUIA_NUBE_Y_RESPALDO.md`.
- La raíz del proyecto queda más limpia para subir a GitHub Pages.

## Qué se mejoró
- Modo Pro Gamer más profesional: fondo dinámico, tarjetas con brillo sutil, mejor profundidad y acabado más premium.
- Panel principal más ordenado para celular y computadora.
- Barra superior más compacta.
- Nuevo soporte PWA: se puede instalar como app y abre mejor desde el celular.
- Respaldo completo sigue guardando productos, ventas, cotizaciones, clientes, gastos, cierres, catálogos y notas/chats.

## Carpetas principales
- `assets/`: logo, iconos y placeholders.
- `css/`: estilos visuales.
- `js/`: funcionamiento de la página.
- `apps-script/`: backend para Google Sheets.
- `docs/`: instrucciones.
