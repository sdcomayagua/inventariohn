# Estructura del proyecto

index.html: panel privado para administrar productos, ventas, cotizaciones y respaldos.
cliente.html: catálogo limpio para cliente.
assets/img/logo-sdc.png: logo oficial.
css/: estilos separados por base, app, móvil y cliente.
js/: configuración, guardado local, nube y lógica principal.
apps-script/Code.gs: backend para Google Sheets.
docs/: instrucciones privadas.
