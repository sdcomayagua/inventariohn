# Guía rápida del panel privado SD COMAYAGUA

Esta página es para administración interna. No compartas el enlace como catálogo público si contiene ventas, costos, ganancias, PIN o información de clientes.

## Qué se guarda

El sistema guarda productos, ventas, cotizaciones, clientes, gastos, cierres, catálogos, notas/chats internos, configuración y respaldos.

## Nube

1. Tocá el botón **Nube** o el botón privado **⚙**.
2. La URL de Apps Script ya aparece precargada.
3. Escribí el PIN de nube.
4. Tocá **Guardar y probar conexión**.
5. Si responde correctamente, usá **Sincronizar ahora** o **Respaldar todo ahora**.

## Respaldo total

El botón **Respaldo** reúne todo en una sola zona:

- Respaldar todo en Google Sheets.
- Descargar un JSON completo.
- Restaurar un respaldo JSON.
- Crear copia local.
- Exportar ventas/clientes CSV.

## Vista cliente limpia

El archivo `cliente.html` muestra una versión limpia del catálogo sin herramientas privadas. Sirve para revisar cómo se verían los productos sin botones de administración.

## Recomendación de seguridad

Usá un PIN de nube diferente a tu contraseña principal. Si alguna clave fue compartida en conversación o capturas, cambiala en Apps Script y en el panel.
